# Rolling Topik Mobil

Game rolling pertanyaan cinta buat tongkrongan di mobil. Buka di HP, langsung main.

Main: https://chronomark29.github.io/rolling-topik-mobil/

## Fitur
- 4 gaya main: Mode santai (aman buat keluarga & kantor), Alur deep, Full semua, Acak bebas.
- 13 ronde, 73 pertanyaan, level 🌱 Santai / 🔥 Deep / 🌶️ Pedas.
- Penanya pilih penjawab (tap atau acak), kartu bisa di-swipe.
- Pertanyaan bikinan sendiri + kirim pack ke tongkrongan lain lewat link.
- Reaksi 🔥😳😂 per kartu, awards di akhir, share kartu & hasil jadi gambar story.
- Pertanyaan malam ini (sama buat semua orang tiap hari).
- Bisa di-install ke home screen dan jalan offline (PWA).

Satu file `index.html`, tanpa backend. Data tersimpan di browser masing-masing.
